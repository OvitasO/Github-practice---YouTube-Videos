# YouTube Layout Practice

Учебный проект по HTML/CSS.

Я практикую вёрстку интерфейсов, работу с flexbox, SVG-иконками, fixed header, scrollbar, hover-эффектами и адаптацией элементов под стиль YouTube.

Проект не является точной копией YouTube и сделан только для обучения.

## Что уже сделано

- Header в стиле YouTube
- Поисковая строка
- Иконки справа
- Кастомный scrollbar
- Список видео
