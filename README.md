# YouTube Layout Practice

A learning project where I recreate parts of the YouTube interface using HTML and CSS.

The main goal of this project is to practice frontend layout, spacing, positioning, SVG icons, hover effects, fixed headers, custom scrollbars, and general UI recreation.

This is not meant to be a full YouTube clone or a production-ready website. It is just a practice project made while learning HTML/CSS.

## What is implemented

- YouTube-style header
- Left header section with menu icon and YouTube logo
- Center search bar
- Search input focus state
- Search button
- Right header icons
- Avatar area
- Custom scrollbar
- Video list layout
- Dark theme styling

## What I practiced

- HTML structure
- CSS Flexbox
- SVG icons
- Hover states
- Fixed header
- `z-index`
- `backdrop-filter`
- Custom scrollbar styling
- Working with spacing, alignment, and visual details

## Planned improvements

- Sidebar navigation
- Video duration badges on thumbnails
- Tooltips for header icons
- Better responsive layout
- Keyboard icon inside the search bar
- More accurate spacing and sizing
- JavaScript behavior later

## Notes

Some text in the interface is in Russian because the layout was based on a localized YouTube page. The project itself is focused on layout and styling practice, not on the language of the content.
